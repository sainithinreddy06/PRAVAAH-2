# PRAVAAH-2

Integrated AICTE approval workflow automation, compliance monitoring, and alert management platform.

## Phase 1 — Frontend foundation

This phase establishes a responsive React + TypeScript + Vite application shell, reusable visual foundations, and the initial PRAVAAH workspace dashboard.

### Requirements
- Node.js 20 or newer
- npm

### Run locally
1. Run `npm install`.
2. Run `npm run dev`.

### Checks
- `npm run typecheck`
- `npm run build`
- `npm run lint`

### Current scope
- Responsive navigation and dashboard layout.
- Overview metrics and synthetic sample queue.
- Initial routes for applications, scrutiny, compliance, evidence, workflows, institutions, officers, policies, and settings.
- Responsive breakpoints and workspace placeholders.

**Important:** Dashboard figures and case names are synthetic demonstration data, not official AICTE records. Most routes are Phase 1 placeholders. Authentication, backend APIs, persistent records, authorization, and live notifications are planned for later phases.
